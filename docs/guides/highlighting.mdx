---
title: Highlighted excerpts
---

Enable the **Meilisearch highlighting** processor on the index (**Processors** tab) and add the **Excerpt** field to your view.

| Option | Default |
|---|---|
| Fields | All fulltext fields |
| Opening and closing tags | `<strong>`, `</strong>` |
| Excerpt length | 30 words |
| Crop marker | `…` |

Matches are highlighted and cropped by Meilisearch. The module escapes the text before inserting the tags, so markup in indexed content is displayed as text, never rendered. Each result also carries a `highlighted_fields` extra data array.
